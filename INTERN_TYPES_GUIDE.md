## 🔐 Permission Levels

Each intern has different permission levels for their modules:

### **VIEW ONLY** 🔍
- Can see data
- Cannot make changes
- Examples: IT viewing logs, HR viewing timesheets

### **EDIT** ✏️
- Can create and modify own data
- Cannot delete
- Examples: Sales creating quotations, POS processing sales

### **MANAGE** 🔧
- Full control within assigned area
- Create, read, update, delete
- Examples: Warehouse managing inventory, HR viewing all data

## 📝 Creating New Interns

To add a new intern with specific department access:

1. **Create user** in `shared_auth.users` table
2. **Assign role** in `shared_auth.user_roles` using one of:
   - `SALES_INTERN` - For sales department
   - `POS_INTERN` - For cashier/retail
   - `IT_INTERN` - For IT department
   - `WAREHOUSE_INTERN` - For warehouse
   - `HR_INTERN` - For HR department
   - `INTERN` - For general interns
3. **Assign permissions** in `shared_auth.user_permissions`

Default password format: `$2y$10$intern123` (bcrypt hashed)

## ⚙️ Adding New Modules to Intern Access

To add a new module's visibility (e.g., `DOCUMENTS`):

```sql
INSERT INTO intern_module_visibility
(intern_role, module_name, can_view, can_edit, can_delete, metadata)
VALUES
('SALES_INTERN', 'DOCUMENTS', 1, 1, 0, '{"can_upload": true, "can_share": true}'),
('IT_INTERN', 'DOCUMENTS', 1, 0, 0, '{"can_download": true}'),
-- ... for other roles
```

## ✅ Testing Intern Access

Each intern type has been configured with database-level permissions. When implementing the React UI:

1. Check `user.role` to determine which modules to show
2. Call API endpoints with intern's authentication token
3. Each API will verify role and module access
4. Response will include only permitted data

**Example API call from React**:
```javascript
// Login as Sales Intern
const response = await fetch('/api/sales/quotation/create.php', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    action: 'create',
    customer_id: 123,
    items: [...]
  })
});
// Will succeed ✅

// Login as General Intern trying same endpoint
// Will fail with 403 Forbidden ❌
```
